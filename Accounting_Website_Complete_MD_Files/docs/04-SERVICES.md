## Payroll service — detailed scope
**Target customers:** Growing SMEs with employees, recurring pay cycles and an external payroll process requiring admin support.

**Potential inclusions (jurisdiction dependent):**
1. Payroll setup and collection of required employer/employee inputs via a secure channel.
2. Employee roster maintenance and pay-period input validation.
3. Gross-to-net pay calculations **only if an approved payroll system and country-specific rules are included in contracted scope**.
4. Payslip preparation/distribution through an approved process.
5. Leave/overtime/bonus adjustments where contractually supported.
6. Deductions, contributions and regulatory reporting based on verified local rules.
7. Payroll reconciliation, audit trail, reporting and month-end coordination.
8. New-hire, offboarding and year-end payroll support if contracted.

**Explicit limitations for website MVP:** Marketing page + enquiry only; **the website does not itself process payroll, pay salaries, store employee records, file taxes or connect to banks**.

**Suggested intake questions:** business name, contact, work email, country, number of employees (range), monthly/biweekly/weekly payroll, current provider (optional), support requested, timeframe, message. Avoid collecting employee names, national IDs, bank accounts, salaries and payslips in the contact form.

## Service-page copy framework
- **Headline:** Clear outcome without unrealistic guarantees.
- **Subheading:** Who it's for and what work is involved.
- **What's included:** 4–6 named deliverables.
- **Our process:** discovery → scope and quotation → secure onboarding → recurring delivery.
- **FAQ:** timeframe, data required, tools supported, pricing model, jurisdiction.
- **CTA:** “Request a tailored quote.”

## Packaging suggestion (not set prices)
